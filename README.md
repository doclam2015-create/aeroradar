# AeroRadar

Radar de vuelos en vivo y seguimiento de tus vuelos para iPhone, iPad y Mac (SwiftUI nativo).

- Mapa en vivo con aeronaves coloreadas por altitud, trayectorias, rutas y vista 3D
- Ficha de cada vuelo con foto, ruta, progreso y llegada estimada
- Mis vuelos: seguimiento con avisos de despegue y aterrizaje, pasaporte de viajero
- Aeropuertos con METAR/TAF y tráfico cercano
- Lista de vigilancia y alertas de emergencia (7500/7600/7700)

Datos gratuitos: [adsb.lol](https://adsb.lol), [adsb.fi](https://adsb.fi), [adsbdb.com](https://www.adsbdb.com), [aviationweather.gov](https://aviationweather.gov), [OurAirports](https://ourairports.com).

Abrir `AeroRadar.xcodeproj` en Xcode y compilar para iOS o macOS.
